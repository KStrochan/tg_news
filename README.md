# AI-агент для каналу «Стрий | Новини Стрийщини»

Бот бере свіжі новини Стрия та Стрийського району з RSS-джерел, переписує їх власними словами через Claude,
генерує ілюстрацію під кожну новину і публікує пост у ваш Telegram-канал.
Дублі не публікуються — бот пам'ятає, що вже постив.

## Як це працює (архітектура)

```
sources.json (RSS-джерела)
        │
        ▼
fetch_news.py      — тягне свіжі новини, відкидає вже опубліковані
        │
        ▼
generate_content.py — Claude API пише заголовок, опис поста і промпт для картинки
        │
        ▼
generate_image.py   — генерує ілюстрацію (Pollinations.ai безкоштовно, або OpenAI)
        │
        ▼
post_telegram.py    — публікує фото+підпис у канал через Bot API
        │
        ▼
storage.py           — зберігає посилання опублікованих новин (posted_news.json)
```

`main.py` запускає весь ланцюжок за один прохід і публікує `POSTS_PER_RUN` новин
(за замовчуванням 1 — щоб публікації розтягувались протягом дня, а не сипались пачкою).

---

## Крок 1. Створіть Telegram-бота і дайте йому права на канал

1. Напишіть у Telegram боту **@BotFather** → `/newbot` → задайте ім'я та username.
   Отримаєте токен виду `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxx`.
2. Створіть (або відкрийте) свій канал → **Адміністратори** → **Додати адміністратора** →
   знайдіть вашого бота і дайте йому право **Публікувати повідомлення**.
3. Дізнайтесь ID каналу:
   - якщо канал публічний — просто використовуйте `@username_каналу`;
   - якщо приватний — перешліть будь-яке повідомлення з каналу боту
     **@userinfobot** або **@JsonDumpBot**, там буде `chat_id` виду `-1001234567890`.

## Крок 2. Отримайте ключ Anthropic API

Зареєструйтесь на **console.anthropic.com**, у розділі API Keys створіть ключ
(`sk-ant-...`). Він потрібен, щоб Claude писав тексти постів.

Генерація зображень за замовчуванням налаштована на **Pollinations.ai** —
безкоштовний сервіс без реєстрації і без ключа. Якщо захочете якісніші картинки —
можна підключити OpenAI (`gpt-image-1`), для цього потрібен `OPENAI_API_KEY`
і `IMAGE_PROVIDER=openai` у `.env`.

## Крок 3. Локальний запуск і перевірка (перед автоматизацією)

```bash
cd telegram-news-bot
pip install -r requirements.txt
cp .env.example .env
```

Відкрийте `.env` і впишіть:
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHANNEL_ID`
- `ANTHROPIC_API_KEY`

Перевірте/відредагуйте `sources.json` — список RSS-джерел (можна додавати свої,
головне щоб посилання дійсно віддавало RSS/Atom-стрічку).

Запустіть тестово:

```bash
python main.py
```

Якщо все налаштовано правильно, у консолі з'явиться лог обробки новини,
а в каналі — новий пост із картинкою.

## Крок 4. Автоматизація — щоденний постинг без сервера (GitHub Actions)

Це найпростіший спосіб зробити повністю автоматичний конвеєр, не тримаючи
власний комп'ютер чи VPS увімкненим.

1. Створіть **приватний** репозиторій на GitHub і залийте туди весь проєкт
   (крім `.env` — він і так у `.gitignore`, ключі там не мають зберігатись у коді).
2. У репозиторії: **Settings → Secrets and variables → Actions → New repository secret**.
   Додайте три секрети:
   - `TELEGRAM_BOT_TOKEN`
   - `TELEGRAM_CHANNEL_ID`
   - `ANTHROPIC_API_KEY`
3. Файл `.github/workflows/post_news.yml` вже налаштований запускати `main.py`
   **4 рази на день** (о 8:00, 12:00, 16:00, 19:00 за Києвом) — тобто 4 новини на день,
   розподілені протягом дня. Хочете 3 публікації — просто видаліть один `cron`-рядок.
4. Після пушу в GitHub зайдіть у вкладку **Actions** — там можна запустити workflow
   вручну кнопкою **Run workflow**, щоб одразу перевірити, що все працює в хмарі.
5. Історія опублікованого (`posted_news.json`) автоматично комітиться назад у репозиторій
   після кожного запуску — так бот "пам'ятає", що вже постив, навіть без власного сервера.

### Альтернатива: власний сервер / VPS + cron

Якщо є VPS (або комп'ютер, що постійно увімкнений):

```bash
crontab -e
```

Додайте рядок (публікація о 8:00, 12:00, 16:00, 19:00):

```
0 8,12,16,19 * * * cd /шлях/до/telegram-news-bot && /usr/bin/python3 main.py >> bot.log 2>&1
```

## Фокус: Стрий і Стрийський район

- **Джерела** (`sources.json`): «Діловий Стрий», сайт Стрийської міськради,
  а також обласні стрічки «Твоє місто», ZAXID.NET і «Еспресо.Захід».
- **Фільтр** — для джерел з `"filter": true` бот бере лише новини, де згадано Стрий
  або громади району (список `local_keywords`: Моршин, Сколе, Жидачів, Ходорів,
  Новий Розділ тощо). Ключове слово має стояти на початку слова, тому «стрий»
  знайде «Стрийщина», але не «Австрия».
- **Свіжість** — новини, старші за `max_age_hours` (48 год), не публікуються.
- **Тон і емодзі** — промпт у `generate_content.py`: місцева прив'язка (де, коли),
  тематичний емодзі в заголовку, короткі абзаци, стримано про ДТП і трагедії.
- **Підпис** — під кожним постом посилання на джерело і «👉 Підписатись» на канал.

### Як додати ще джерело

1. Знайдіть на сайті посилання "RSS" (для WordPress — `/feed/`, для Joomla — `?format=feed&type=rss`).
2. Відкрийте URL у браузері — має завантажитись XML, а не HTML-сторінка.
3. Додайте об'єкт у `feeds` в `sources.json` (`name`, `url`, `filter`, `enabled: true`).

Якщо RSS-стрічки немає або вона нестабільна — можна лишити фільтрацію за
ключовими словами як основний механізм відбору саме військових новин із загальних джерел.

## Налаштування під себе

- **Кількість новин на день** — регулюється кількістю cron-запусків у workflow
  (кожен запуск = `POSTS_PER_RUN` новин, за замовчуванням 1). Для 3-4 новин/день
  лишіть 3-4 cron-рядки.
- **Джерела новин** — редагуйте `sources.json`. Можна додати будь-яке RSS,
  зокрема вузькотематичні (спорт, технології, ваше місто).
- **Стиль тексту** — редагуйте `SYSTEM_PROMPT` у `generate_content.py`: можна
  задати тон (серйозний/дотепний), довжину, додати хештеги, емодзі-політику тощо.
- **Стиль зображень** — впливайте через `image_prompt` у тому ж системному промпті
  Claude (наприклад: "мінімалістична векторна ілюстрація" замість "photojournalistic").
- **Дешевша модель** — якщо тексту багато, а бюджет обмежений, поставте
  `ANTHROPIC_MODEL=claude-haiku-5-5` — швидша і дешевша за Sonnet.

## Важливі застереження

- **Авторське право**: бот переписує суть новини своїми словами (це і робить Claude),
  а не копіює текст джерела — так і задумано, щоб не порушувати copyright. Посилання
  на джерело в кожному пості лишається обов'язково.
- **Перевіряйте RSS-адреси**: сайти іноді змінюють структуру RSS. Якщо джерело
  "замовкло", перший крок діагностики — відкрити URL з `sources.json` у браузері
  і переконатись, що там валідний XML.
- **Достовірність**: AI-опис — це переказ, а не журналістська перевірка фактів.
  Для чутливих тем (наприклад, точні цифри, цитати посадовців) варто самостійно
  вибірково перевіряти пости, особливо на старті.
- **Ліміти Telegram**: канал не повинен постити занадто часто (спам-фільтри) —
  4 пости на день з інтервалами це безпечно.

## Структура файлів проєкту

```
telegram-news-bot/
├── main.py                 — точка входу, запускає весь пайплайн
├── config.py                — читає .env та sources.json
├── fetch_news.py            — парсинг RSS
├── generate_content.py      — генерація тексту через Claude API
├── generate_image.py        — генерація зображення
├── post_telegram.py         — публікація в Telegram
├── storage.py                — історія опублікованого (анти-дублі)
├── sources.json              — список RSS-джерел
├── requirements.txt
├── .env.example
└── .github/workflows/post_news.yml  — автоматизація по розкладу
```
